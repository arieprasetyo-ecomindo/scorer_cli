HOW TO USE THIS STRUCTURE
================================================================================

For Users:
  1. Read README.md (2 min)
  2. Read docs/QUICKSTART.md (5 min)
  3. Run: uv run score-cli run-all
  4. Read examples/sample-report.md to understand output

For Judges:
  1. Read examples/sample-report.md (what's in a report?)
  2. Read spec/rubrics.md (what do scores mean?)
  3. Use confidence levels to prioritize manual review

For Developers (Implementing):
  1. Read docs/ARCHITECTURE.md (30 min)
  2. Read spec/rubrics.md (20 min)
  3. Read design/structure-scoring.md (20 min)
  4. Read design/spec-scoring.md (20 min)
  5. Read _archive/IMPLEMENTATION_GUIDE.md for step-by-step
  6. Start coding the 7 modules in score_cli/

For Architects/Leads:
  1. Read README.md
  2. Read docs/ARCHITECTURE.md (full design)
  3. Review design/*.md for implementation details
  4. Adjust config.yaml weights/thresholds as needed
