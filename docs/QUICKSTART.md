# Quick Start — 5 Minutes

## 1. Install

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
git clone <repo>
cd scorer_cli
uv sync
```

## 2. Configure

Copy and fill in credentials:

```bash
cp config.yaml.example config.yaml
export TYPESAFE_API_KEY="sk-..."
export ANTHROPIC_API_KEY="sk-ant-..."
```

## 3. Run

Score a sample submission:

```bash
cp -r fixtures/team-sample-001 submissions/team-sample-001
uv run score-cli run team-sample-001
```

Output: `reports/team-sample-001.md`

## 4. Batch Score All

```bash
uv run score-cli run-all
```

Output: `reports/team-*.md`

## 5. Dry Run (No API Calls)

Compute metrics only:

```bash
uv run score-cli run team-a-007 --dry-run
# Produces: reports/metrics/team-a-007/metrics.json
```

## Expected Output

Reports are markdown files in `reports/`:

```
# Hackathon Submission Report: team-a-007

**Combined Score:** 7.7 / 10

## Structure Quality (Code Metrics)

### Coupling — Weight 21%
| **Score** | 7.5 / 10 |
| **Jev Level** | 4 (Good) |
| **Confidence** | 78% |
| **Justification** | [2–3 sentences from Claude] |

### [5 more structure dimensions...]

## Spec Quality (SDD Scoring)

### [5 spec dimensions...]

## Red Flags
- Function X has CCN > 20
- Spec doesn't mention module Y

---

*Generated by score-cli v0.2.0*
```

## Understanding the Report

Each dimension has:
- **Score:** 0–10 rating
- **Jev Level:** 1–5 (Critical → Excellent)
- **Confidence:** 0–1 (how sure Jev is)
- **Justification:** Claude's explanation

**Low confidence = ambiguous signal → flag for manual review by judges.**

## Troubleshooting

| Issue | Fix |
|-------|-----|
| "Module not found" | Run `uv sync` |
| "API key not set" | `export TYPESAFE_API_KEY=...` and `export ANTHROPIC_API_KEY=...` |
| Jev timeout | Retry automatically happens; check TypeSafe status if persistent |
| LLM timeout | Falls back to auto-generated markdown (scores only) |
| "submission missing files" | Ensure graph.json, source.zip, sdd.zip are present |

## Common Tasks

### Recompute Reports from Existing Metrics (No API Calls)

```bash
uv run score-cli recompute reports/metrics/team-a-007/metrics.json
```

Useful if you change `config.yaml` weights and want fast re-scoring.

### Check Scoring Progress

```bash
ls -1 reports/*.md | wc -l  # Count completed reports
```

### Export Scores to CSV

```bash
uv run score-cli export --format csv > scores.csv
```

(Future feature; not yet implemented)

## For Implementers

You're building these modules:

1. **jev_scorer.py** — Build Jev questions, call TypeSafe API
2. **scoring_engine.py** — Map Jev answers to 0–10 scores
3. **llm_reporter.py** — Call Claude with scored_data, get markdown
4. **report_generator.py** — Write markdown to disk, format output

See `DEVELOPER_CHECKLIST.md` for full details.
